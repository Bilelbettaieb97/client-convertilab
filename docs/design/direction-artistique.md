# Direction Artistique - ConvertiLab

## Positionnement

ConvertiLab se positionne comme une **agence web premium**, moderne et tech, basee a Rueil-Malmaison (Ile-de-France). L'identite visuelle traduit une approche **data-driven** orientee resultats, tout en restant accessible aux TPE/PME.

Le site doit communiquer :
- La **competence technique** (stack moderne, performance, SEO)
- La **fiabilite** (+50 clients, +280% de CA moyen, 4.9/5 de note)
- L'**accessibilite tarifaire** (a partir de 500 euros, offre mensuelle a 39 euros/mois)

## Univers Visuel

### Palette dominante
- **Violet** (`hsl(270 70% 60%)`) comme couleur primaire : autorite, innovation, creativite
- **Rose** (`hsl(330 70% 60%)`) comme couleur accent : energie, dynamisme, conversion
- **Gradients violet-rose** : signature visuelle presente sur tous les CTA et elements cles

### Effets visuels
- **Glassmorphism** : fond semi-transparent blanc (70% opacite) + blur 10px + bordure blanche 18% opacite
- **Glow effects** : ombres lumineuses violettes (box-shadow 40px rgba violet 30%)
- **Gradient shift** : animations subtiles sur les backgrounds (200% 200%, mouvement lent)
- **Grid pattern** : motif de points violet/rose en arriere-plan (radial gradients)
- **Scrollbar personnalisee** : degrade violet vers rose

### Animations
- **Fade in** : apparition avec translation de 30px vers le haut (1s ease-out)
- **Scale in** : zoom de 0.8 a 1 (0.8s ease-out)
- **Slide up** : translation de 50px vers le haut (1s ease-out)
- **Float** : mouvement de levitation (3s infinite, -20px)
- **Shimmer** : effet de brillance (2s infinite)
- **Glow pulse** : pulsation de l'ombre lumineuse (2s infinite)
- **Respect de `prefers-reduced-motion`** : toutes les animations sont desactivees si le user le demande

## Mood

**Professionnel mais dynamique.**

Le site inspire confiance grace a :
- Des preuves sociales omni-presentes (chiffres, temoignages, notes)
- Un design epure et structure (espaces genereux, hierarchie claire)
- Des micro-animations qui guident le regard sans distraire

L'aspect dynamique vient de :
- Les gradients vivants et les effets de glow
- Les transitions fluides sur tous les elements interactifs (300ms ease-out)
- Le glassmorphism qui donne de la profondeur

## Tone of Voice

| Dimension | Description |
|-----------|------------|
| **Expert** | Vocabulaire precis (ROAS, CPA, SEO on-page, netlinking) sans etre jargonneux |
| **Accessible** | Explication des benefices en termes concrets ("de 5 a 30 demandes de devis par semaine") |
| **Oriente resultats** | Chaque service est lie a un KPI ou un benefice mesurable |
| **Rassurant** | "Devis gratuit", "sans engagement", "livraison rapide", "prix fixe garanti" |
| **Local** | Ancrage Paris/Ile-de-France, adresse physique, numero de telephone affiche |
